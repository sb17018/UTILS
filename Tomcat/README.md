# *Tomcat server generated programatically*

#### After building a jar file it can be run either by [1.] CMD or by [2.] double-click of the jar file.
> *`NOTE:`*
> - [1.] Let see logs. Can be stoped by clicking Ctrl + c in the console or closing the console. 
> - [2.] When run, can be stopped only by ending the task in a Task Manager.
