# *Tomcat server generated programatically with cursor's coordinates checker*
### Tomcat runs on one thread, while on another an infinite loop runs to check cursor's location. Checking cursor's coordinates is to determine if users works with mouse or not.
#

#### After building a jar file it can be run either by [1.] CMD or by [2.] double-click of the jar file.
> *`NOTE:`*
> - [1.] Let see logs, including current cursor's location displayed in a set interval. Can be stopped by clicking Ctrl + c in the console or closing the console. 
> - [2.] When run, can be stopped only by ending the task in a Task Manager.

---
### *Concepts used:*
- Tomcat - servlet container
- Servlet
- Point - cursor's location
- Threads
